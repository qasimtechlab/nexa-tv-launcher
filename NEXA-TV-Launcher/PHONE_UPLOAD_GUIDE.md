# Phone upload guide

This project is published in the GitHub repository. To get a source ZIP, open the repository page and choose Code → Download ZIP.

To build the APK:
1. Open the repository Actions tab.
2. Select the NEXA source build workflow.
3. Run workflow, or wait for the push-triggered build.
4. Open the successful run and download the NEXA-TV-Launcher-debug-APK artifact.
5. Extract the artifact ZIP to get app-debug.apk.

Install first as a normal app and test D-pad navigation. Keep the factory launcher enabled until the new launcher has been tested.
