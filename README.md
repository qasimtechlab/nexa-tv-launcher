# NEXA Smart TV Launcher

Native Android TV launcher project by **Mirza Qasim** (Faisalabad, Pakistan).

## Project source

The complete Android Studio project is in [NEXA-TV-Launcher/](NEXA-TV-Launcher/).

## Build an APK

1. Open the **Actions** tab.
2. Select **Build NEXA TV Launcher APK**.
3. Wait for the workflow to finish successfully.
4. Open the run's **Artifacts** section and download **NEXA-TV-Launcher-debug-APK**.
5. Extract the artifact ZIP to get app-debug.apk.

Every source change triggers an automated build. The workflow runs unit tests and Android lint before assembling the debug APK.

## Important

This is an early development build. The first successful cloud build still needs testing on the target Android TV box. Keep the factory launcher enabled until NEXA has been installed and tested safely.

BixSigma AI currently includes its creator identity and interface only. Live provider integration is not enabled in this release.
