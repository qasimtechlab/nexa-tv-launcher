# NEXA Smart TV Launcher

Native Android TV launcher project by **Mirza Qasim** (Faisalabad, Pakistan).

## Current version

**NEXA Smart TV Launcher v1.2.0**

The source includes BixSigma AI chat, category-based YouTube video cards with thumbnails, Favorites and app long-press actions, wallpaper customization, a moveable clock widget and animated Futuristic Widgets.

## Project source

The complete Android Studio project is in [NEXA-TV-Launcher/](NEXA-TV-Launcher/). See its [full README](NEXA-TV-Launcher/README.md) for setup, features and compatibility notes.

## Download the test APK

After the v1.2.0 GitHub Actions build succeeds, the APK is copied to:

`releases/NEXA-TV-Launcher-v1.2.0-debug.apk`

You can also download the `NEXA-TV-Launcher-debug-APK` artifact from the successful run's **Artifacts** section. Extract the artifact ZIP to get `app-debug.apk`.

## Important

This is a debug build for testing on the target Android TV box. Keep the factory launcher enabled until NEXA has been installed and tested safely. Do not select NEXA as the permanent default Home app until remote navigation, app launching, YouTube, wallpaper and widget behavior are verified.
