# NEXA Smart TV Launcher

Native Android TV launcher project by Mirza Qasim (Faisalabad, Pakistan).

## Source package
The complete Android Studio project is provided in `NEXA-TV-Launcher-v1-source.zip`.

## Build
The GitHub Actions workflow extracts the source package, runs unit tests and Android lint, builds the debug APK, and uploads it as an Actions artifact.

## Important
This is an early development build. A successful cloud build is not a substitute for testing on the target Android TV box. BixSigma AI is currently an identity/interface module only; provider activation is intentionally inactive pending policy and security review.
