Get started

Install in three simple steps

Install Nexa as a normal Android app first. Keep your device's original launcher available while testing.

Download the APK

Open the download button on your TV browser, or download on a phone and transfer the APK to your TV box.

Allow installation

When Android asks, allow your browser or file manager to install apps from this source, then open the downloaded APK.

Launch and test

Open Nexa from Apps. Test D-pad, OK and Back navigation before choosing it as the default Home app.

Need to know

Frequently asked questions

Is Nexa TV Launcher free?

Yes. The website provides a free direct download of the current debug/test APK.

Does it work with a TV remote?

The interface is designed for D-pad, OK/Center and Back navigation. Actual behaviour can vary with device firmware and remote configuration.

Do I need a YouTube API key?

No API key is required for the curated public channel upload feeds included in version 1.2.1. These feeds show recent uploads from the included channel list, not global YouTube search or private personalized recommendations.

Will Nexa replace my factory launcher?

Installing Nexa does not uninstall or modify the factory launcher. Test Nexa first and keep the original launcher available so you can switch back.

How will future APK updates work?

The website uses a permanent download address. When a new version is released, the latest APK file can be replaced in the project repository and the website's download button will continue pointing to the same address.

Is this an official Google or YouTube product?

No. Nexa TV Launcher is an independent project by Mirza Qasim and is not affiliated with Google, Android, or YouTube.
