Free Android TV Launcher for TV Boxes

App details

NEXA TV Launcher is a native Android TV home-screen launcher designed for compatible Android TV devices and TV boxes. It gives your television a clean home screen where you can open installed apps, arrange favourites and navigate with a TV remote instead of relying on a touchscreen. If you are looking for an Android TV launcher APK, a smart TV launcher for a compatible TV box, or a customizable TV home screen, NEXA brings these tools into one free-to-download app.

Created by independent developer Mirza Qasim, NEXA combines a remote-first app library with wallpaper controls, home-screen widgets, curated Hindi and Urdu public video feeds, and BixSigma AI chat. Device firmware can affect launcher selection and individual features, so install and test NEXA before setting it as your default Home app.

Android TV Launcher Features

Remote-first navigation

Move around the launcher with the remote's directional pad, OK or Center button, and Back button. NEXA is designed for a big-screen television interface.

Apps, favourites and layouts

Browse installed apps in Grid or Rows layouts, add favourites, arrange app positions and open app options with a long press on OK or Center.

Wallpapers and appearance

Choose from built-in gradient wallpapers or a local image, adjust framing and overlay, and select Glass, Dark or Light appearance with an accent colour.

Clock and movable animated widgets

Use the clock and date with the optional Rotating Earth or Orbital Reactor. Hold OK on a Home widget to open its options, choose Move widget, use the remote arrows to position it, press OK to save, or Back to cancel. Normal arrow presses scroll and navigate as usual.

Pakistani and Indian video categories

Browse 22 categories with 212 named Pakistani, Indian and Hindi/Urdu channel entries, including news, dramas, music/naats, learning, gaming, food, sports, travel and vlogs. If a selected category has no active public uploads, NEXA tries alternate categories; if none load, open that category directly in YouTube. This is a curated catalogue, not a claim that thousands of feeds are active.

BixSigma AI assistant

Use BixSigma AI chat and natural Gemini-generated spoken replies with your own API key. Each reply's speaker control starts or stops playback. The Add API key dialog includes a remote-friendly clipboard Paste button. Voice generation needs internet access and TTS model availability/quota.

How to Download and Install NEXA TV Launcher

The NEXA TV Launcher download is provided as an APK file for compatible Android TV devices and TV boxes. This is a direct APK download from the project release repository, not a Google Play Store installation.

  1. Select the Download / Install button to get the latest NEXA APK.
  2. Open the downloaded APK from your TV's Downloads folder or file manager.
  3. If Android asks, allow your file manager or browser to install apps from that source, then continue with the installer.
  4. Open NEXA from the TV Apps list and test remote navigation and the apps you use.
  5. Only after testing, choose NEXA as your default Home app if your TV firmware offers that option. Keep the factory launcher available while testing.

Release notice: the currently published APK is a debug/test build and is not a production-signed Google Play release. Compatibility and default-launcher options can vary by device manufacturer and firmware.

Android TV Launcher – Frequently Asked Questions

What is NEXA TV Launcher?

NEXA is a native Android TV home-screen launcher. It helps you open and organize installed apps, manage favourites, customize wallpapers and navigate your TV with a remote.

Is NEXA TV Launcher free to download?

Yes. The NEXA APK download is free. BixSigma AI chat uses an API key supplied by the user, and AI usage may be subject to the API provider's free-tier limits, quotas and terms.

Can I install NEXA on an Android TV box?

NEXA targets Android 5.0 (API 21) and later and is designed for Android TV devices and compatible TV boxes. Actual installation, launcher selection and feature support depend on the device firmware.

Does NEXA support a TV remote?

NEXA is designed around D-pad directional navigation, the OK or Center button and Back. Exact remote behaviour can vary by TV box and its firmware.

Can I move widgets with my TV remote?

Yes. Hold OK or Center on the clock or animated widget to open its options. Choose Move widget, use LEFT, RIGHT, UP and DOWN, then press OK to save. Press Back to cancel. Ordinary arrow presses continue normal focus navigation and scrolling.

Can I rearrange apps and customize the TV home screen?

Yes. The app library supports Grid and Rows layouts, favourites and manual app ordering. You can also customize wallpapers, framing, overlay, appearance and Home widget positions.

Does NEXA show personalized YouTube recommendations?

No. NEXA displays recent public uploads from a curated list of Pakistani and Indian YouTube channels. It does not read private watch history, perform global YouTube search or reproduce the signed-in account's recommendation algorithm.

Can BixSigma AI read replies aloud naturally?

Yes. Use the speaker control under an AI reply to generate natural spoken audio with Gemini TTS, then press the same control again to stop. This requires internet access, your own Gemini API key and TTS model availability on that API project.

Does BixSigma AI need an API key?

Yes. BixSigma AI chat and Gemini-generated speech use the user's own API key. Add API key includes a Paste from clipboard control for TV remotes. The public APK does not contain a shared developer key because client-side keys can be extracted and abused. Voice playback also depends on TTS model access and quota.

Is NEXA TV Launcher available on Google Play?

No. This page provides a direct APK download for testing. NEXA is an independent project and is not an official Google or Android product.

Is the current NEXA APK production-signed?

No. The currently distributed APK is a debug/test build, not a production-signed release. Install it for testing and keep your factory launcher enabled until you have checked compatibility.
