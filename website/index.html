Before you install

Is NEXA TV Launcher on Google Play?

This page provides a direct APK download. It is not a Google Play Store listing and NEXA is an independent project, not an official Google product.

How do I install the APK?

Download the APK, open it from your TV's Downloads or file manager, and allow installation from that source if Android asks. Keep your existing launcher available while testing.

Will it work with my TV remote?

NEXA is designed for D-pad, OK/Center and Back navigation. Exact behaviour can vary by TV box firmware and remote configuration.

Is this a production-signed release?

The currently distributed APK is a debug/test build. It is intended for testing and is not represented as a production-signed Play Store release.
